# CalibriAI Importer

Локальное расширение для Яндекс.Браузера / Chrome / Edge. Читает уже открытую страницу вакансии на hh.ru и отправляет её в `http://localhost:3000`.

## Установка в Яндекс.Браузере

1. Запустите приложение: `npm run dev`.
2. Откройте `browser://extensions` или `chrome://extensions`.
3. Включите «Режим разработчика».
4. Нажмите «Загрузить распакованное расширение».
5. Выберите папку `extension` из этого проекта.
6. Откройте вакансию на hh.ru и нажмите иконку расширения → «Отправить в CalibriAI».

Перед отправкой нужны активное резюме и OpenAI API-ключ в настройках приложения.
